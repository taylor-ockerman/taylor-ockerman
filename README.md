## Featured Projects

### Sandy Sim — Custom C++ Game Engine

Custom ECS/OOP game engine and particle simulation built using SDL3.

Features include:

* Real-time particle simulation
* Modular rendering and input systems
* Dynamic UI and camera systems
* Performance optimization through chunk-based updates
* Collision handling and material interaction systems

**Tech:** C++, SDL3, ECS Architecture

Web forum application developed as part of a five-person team at BCIT.

Contributions included:

* Front-end implementation using React and TypeScript
* UI/UX component architecture
* Integration of Google Gemini AI enhancements
* Collaborative Git-based development workflows

**Tech:** React, TypeScript, JavaScript
